# 首页沙龙板块重构设计

- 日期：2026-11-14
- 范围：首页（`/`、`/zh-HK`、`/en`）培训赋能区
- 目标：把「第 2 期 出海 + AI 线下实战沙龙」同步到首页，替换原有深色预告横幅，形成信息完整、可视化的一屏板块

## 背景

首页现有 13 个区块，培训赋能区位于第 10 位，结构为：3 张培训卡片 + 1 条深色「下期预告」横幅。培训页已经具备完整的沙龙内容（关键信息、三位主讲、宣传图、到场权益、报名），首页仅有一句文案和一个跳转按钮，信息密度不足。

本次只同步沙龙内容，不改动其他区块，不调整培训区在页面中的位置。

## 设计

### 结构与视觉

板块位于培训区内部，背景沿用 `bg-surface`，与上方 3 张培训卡片通过 `mt-12` 分隔。

1. 标题区（左对齐）
   - 小标：`最新一期 · 第 2 期`
   - 主标题：`「出海 + AI」线下实战沙龙`
   - 摘要：时间、地点、席位一句话
2. 双栏主体（`lg:grid-cols-[1fr_minmax(0,520px)]`）
   - 左栏：摘要段 → 2×2 信息卡（时间 / 地点 / 席位 / 费用，费用卡附权益说明）→ 报名按钮（amber 主按钮，直达 `/contact?type=salon`）→ 联系电话
   - 右栏：三张宣传图竖向错落，首张大图，下方两张并排
3. 主讲区（`lg:grid-cols-3`）：编号 + 标签、主题、姓名 · 职务、一句简介、2 个成绩标签
4. 删除原深色「下期预告」横幅，避免重复入口

### 内容与数据

- 数据复用现有 `SALON`、`SALON_PERKS`，不新增数据源
- `homeCopy.training` 中删除 `eventEyebrow` / `eventTitle` / `eventDesc` / `eventCta`，新增：
  - `salonEyebrow`、`salonTitle`、`salonSummary`
  - `salonInfoLabels`（时间、地点、席位、费用、席位说明、费用权益说明）
  - `salonSpeakersTitle`、`salonCta`、`salonContactNote`
  - `salonImages`（3 张图的 `src` / `alt`）
- 三语：修改 `zh/home.ts` → 运行 `node scripts/gen-hk.mjs` 生成繁中 → 同步 `en/home.ts`（类型源自 zh）

### 实现

- 仅修改 `app/[lang]/page.tsx` 的 Training 局部函数，沿用 S1–S11 的局部组件写法，不新增组件文件
- 移动端顺序：标题 → 摘要 → 信息卡 2×2 → 报名 → 三张宣传图缩略 → 主讲卡单列；桌面为双栏
- 容器继续使用 `max-w-8xl`（1600px 版心）

### 不在本次范围

- 首页其他区块的顺序、删减与视觉改版
- 培训卡片的内容与顺序调整
- 沙龙结束后自动隐藏/过期机制

## 验收

- `npx tsc --noEmit`、`npm run lint` 通过
- `/`、`/zh-HK`、`/en` 均返回 200，沙龙板块文案为对应语言
- 桌面端双栏、移动端单列；1600px 版心下无溢出、无横向滚动
- 原「下期预告」横幅不再出现
